# Advertorial Landing Page (Keto Probiotix)

Адаптивный одностраничный лендинг (Advertorial), стилизованный под статью из модного журнала (вдохновлен дизайном и контентом Grazia.it). 
Проект выполнен в рамках тестового задания. Основная задача — создать убедительную имитацию блога с интеграцией карточки товара и интерактивных элементов.

## ✨ Реализованный функционал

- **Адаптивная верстка**: Полностью отзывчивый дизайн. На десктопе контент центрируется в узкую колонку (как в блогах), а на мобильных устройствах текст и картинки аккуратно масштабируются.
- **Валидация формы (JS)**: Написана кастомная валидация для полей имени и телефона. Проверяется длина имени и формат телефона (только цифры, от 8 до 15 символов) с выводом ошибок под полями ввода в реальном времени.
- **Таймер обратного отсчета (JS)**: Динамический таймер (30 минут), который создает эффект срочности для оформления заказа. По истечении времени останавливается.
- **Мобильное меню**: Кастомный бургер-меню для смартфонов (открытие/закрытие навигации).
- **UX/UI**: Стилизованы кнопки с эффектами наведения (hover), добавлены стили для формы в виде карточки товара, адаптированы комментарии "читателей".
- **Страница благодарности**: Отдельная страница (`success.htm`) с приятным дизайном после успешной отправки формы.

## 🛠 Стек технологий

- **HTML5** (семантическая верстка, доступность форм)
- **CSS3** (Flexbox, медиа-запросы, кастомные стили для карточек и типографики)
- **Vanilla JavaScript** (работа с DOM, регулярные выражения, таймеры, обработка событий)
- Без использования сторонних библиотек и фреймворков.

## 🚀 Как запустить

1. Скачайте файлы или склонируйте репозиторий.
2. Откройте файл `index.html` в любом современном браузере.
3. Заполните форму и нажмите «Acquistare», чтобы проверить работу валидации и переход на страницу успеха.

## 📱 Брейкпоинты

- Десктоп: `> 768px` (контент в колонку)
- Мобильные устройства: `< 768px` (появление бургер-меню, перестройка карточек)
